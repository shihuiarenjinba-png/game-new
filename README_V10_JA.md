## 動作確認のしかた

ZIPでこのブランチを取得・展開し、`index.html` をEdge/Chromeで開いてください。ゲーム内のWeb API、外部AI、広告、アカウント、課金フォームはありません。

Node.jsがある場合、`npm test` で物語・推理・保存・読書用編集の自動テストを実行できます。

WindowsでMicrosoft Edgeが入っている場合、`npm run test:edge:win` で6ルートの画面操作を自動検査できます。1366px相当と390px相当の描画を確認し、代表画面のPNGを `browser-smoke-output/` に出力します。このコマンドは**MSIXを作成しません**。

## GitHub Actionsの注意

GitHub ActionsでもWindows Edgeの操作検査を実施します。ただし、GitHubのアーティファクト保存容量が上限に達しているため、PNGの自動アップロードは停止しています。画像の生成と検証は継続し、ログに寸法とハッシュを残します。画像を永続保存するにはローカルで同コマンドを実行してください。
