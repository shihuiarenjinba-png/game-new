# 引継ぎ室 v0.2 — 2章構成の心理ミステリー（商用品質検証中）

**進行状況: 体験版候補 / 販売HOLD**

工場事故について「本人の判断だった」と全員が同じ説明をする。誰かが嘘をついているのか、それとも全員が自分の立場で本当だと思っているのか。現実に起こり得る心理的な怖さを描きます。

## ブラウザで試す

1. この開発ブランチをGitHubからZIPで取得。
2. 全ファイルを同じフォルダーへ展開。
3. index.html をEdgeまたはChromeで開く。
4. 第一夜を進め、最後の画面に現れる「翌朝の調査を始める」を選ぶ。

サーバー、API、AIチャット、インターネット接続は不要です。外部へのプレイ情報送信もありません。

## 開発・動作確認

Node.js 20以上で npm test を実行。GUIは引き続きWindows実機での手動確認が必要です。

Windowsアプリ化の検証には npm install の後に npm run start:desktop を使用できますが、この起動方式は本番品質・インストール試験未実施です。

MSIXビルドには、正式な新作専用のStore登録情報と製品ロゴが必要です。未設定なら npm run build:msix は意図的に失敗します。商用品としてMSIXを作成・提出する段階ではありません。
