# 引継ぎ室 v0.5 — 周回型心理ミステリーの制作・品質基準

**開発対象：game-new / feature/handover-v05-replayable-cases**
**商品化：HOLD。Windows実機評価・商用検証・Store登録は未実施。**

## 狙い

プレイヤーが別の周回で同じ文章を読むのではなく、**なぜ同じ説明が生まれたのかという理由と、人々の行動の因果関係が変わる**ようにする。

ランダムに事件や伏線を寄せ集めると、見つかっていない証拠を主人公が知っていたり、回収時に登場人物の行動と矛盾したりする。そのため、ゲーム開始時に真相を固定する **制約付きシナリオ構成** を採用した。

## 現段階の内訳

| 要素 | 内容 | 通り数 |
| --- | --- | ---: |
| 匿名の封筒を書いた人物 | 班長・荻野、同僚・真帆、本人・佐原、事務担当・川島 | 4 |
| 隠した動機 | 4人物それぞれに独立して執筆した3動機（合計12パターン） | 3 |
| 副次的な出来事 | 勤務表の書き換え、休憩室のマグカップ、折り込まれた引継ぎノート | 3 |
| 空気感 | 雨の工場、換気扇の残響 | 2 |
| **編集済みの組み合わせ** | 4×3×3×2 | **72** |

**注意：72本の完全に独立したストーリーではない。** 背景の主筋、登場人物、基本の選択画面は共通。事件の意味・伏線・動機・回収が72組から固定される設計。無限生成や自動AI執筆を装わない。

## 伏線を勝手に回収しないための条件

1. まず「どの人物がなぜ封筒を書いたか」を、ゲーム開始時のシードで固定する。
2. プレイヤーが対応する第一夜の記録を調べた場合のみ、固有の痕跡を証拠として追加する。
3. 翌朝に封筒の文字を調べた場合のみ、筆跡や印などの一致を発見できる。
4. 特定の会話でさらに証言を得られた場合のみ、筆者の証明につながる。
5. 条件が満たされなかった場合は筆者不明のまま結末に進む。「見ていない証拠を見た」扱いにしない。
6. 推理パートには、実際に得た固有の記録を照合候補として渡す。
7. 最終報告の「断定・保留・慎重な記録」と、推理の「断定・未確認を残す・疑問の切り捨て」に応じて後日談を変える。

事件の大きな回収方針は **「証明できた」「疑いは残った」「誤った断定をした」** を中心に設計する。異なる人格や立場の利害が会話に影響する構成とし、ただ優しく話す選択肢だけが常に得にならないよう調整する。

## 周回とセーブ

- 初回の事件番号は端末内でランダムに選ぶ。
- 終了画面に「別の事件を調査する」を追加。選択すると、未使用の次の組み合わせへ進む。
- 72組すべて経験するまで、新しい組み合わせが重複しない循環順序とした。順番は初回選択から決定論的。端末を新規化したり保存を書き戻した場合は重複の可能性がある。
- 同じ事件を違う質問からやり直すこともできる。
- 既存の v0.1 / v0.2・v0.3 / v0.4 のセーブは、過去の経緯を後付けせず **legacy として復元**。新しい事件を始めたときから周回設定を使う。
- v0.5のバックアップは事件番号と推理の進行も保存。外部通信・外部AI・課金は行わない。

## UIルール（新しい機能は裏側へ）

- 主要操作はこれまでの1列3択。タブと常設サブ画面は増やさない。
- 新しいヒントも、既存の「あなたが見たもの」に折りたたみ式で格納。
- 新事件 / 同事件の再調査は結末にだけ表示。プレイ途中で混乱させない。
- 主人公が既に知る根拠と、新たに聞いた情報を分ける。
- 文字量が多くなる問題はWindows実機のスクロール検査で確認し、必要ならシーンを短く整理する。自動テストのみで見栄えの保証をしない。

## 自動テストで求めること

- 72組の組み合わせが重複しないこと
- 同じ事件番号なら、同じ物語上の裏設定・伏線・動機・回収が再現されること
- 全72組で、筆者の回収に至る調査ルートがあること
- 必要な証拠を調べなかった場合、伏線が勝手に回収されないこと
- 封筒が届く前に、その筆跡・証言が手に入らないこと
- 推理の証拠に、未発見のものを使えないこと
- 旧セーブの復元で架空の新事実を追加しないこと
- ランダムなケースIDが無効の場合に保存データを拒否すること
- UIは従来の一つのストーリーパネル・折りたたみ証拠欄を維持
- 既存の全分岐とMSIX販売HOLDの検証も維持

## まだ不足する商用品質

1. **何度も遊びたくなるかの第三者試遊：** 72組でも共通場面の多さが目立つなら、独立の物語パケットと会話を増やす必要がある。数だけでは評価しない。
2. **人間心理の自然さ：** 筆者の動機と人物ごとの知識、現場での力関係を脚本家視点でチェックし、不自然な偶然や唐突な告白を減らす。
3. **視聴覚的な完成度：** 現状はテキスト主体。有料販売にふさわしい独自の演出は未実装。
4. **GUI・ストア：** Windows 11実機、DPI、クリック、セーブ、MSIX、正式Identity、ストア商品ページの審査は未実施。
5. **価格と購入意向：** 無料競合との比較・購入意向の試遊調査をするまで、有料製品としての適格性は未確定。
