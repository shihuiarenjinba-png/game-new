# 引継ぎ室 — 全員が同じことを言う夜

**状態：心理ミステリーの第1試作（v0.1 / 開発用）**

> 三人が事故について同じ説明をした。きれいに揃ったその言葉は、誰の言葉なのだろう。

事故の原因を機械的に判定する作品ではありません。外部調査員となり、職場の雇用不安・沈黙・同調圧力・かばい合いの中にある不気味な理由を探ります。

## 起動

1. このブランチをZIPで取得して任意のフォルダーに展開する。
2. 同じフォルダーにある \`index.html\` をEdgeまたはChromeで開く。
3. 画面に出る選択肢を選び、調査メモと最後の報告を確認する。

インターネット・AI・APIキー・Node.jsのインストールはプレイに不要です。音楽・画像の外部取得もありません。ローカルセーブは使用ブラウザーの設定によって利用できない場合があります。

## 現在できること

- 事故後に「本人の判断だった」と繰り返す現場の人々を調べる
- 一度に一つの証拠を選び、会話相手への聞き方を選ぶ
- 憶測と事実を区別したまま最後の報告方法を決める
- 243通りの選択列から5種類の心理的結末に分岐
- リスタート、端末内への途中保存（利用可能環境のみ）

**制約：** 第一夜だけを収録した短編デモ。実際に起動してのWindows GUI検証、第三者試遊、商用水準の演出検証は未了です。MSIXは未作成です。

## テスト

Node.js 20以降がある環境では \`npm test\` を実行します。物語分岐、証拠保存、復元、全パスの到達可能性を検査します。
