# 引継ぎ室 v0.8 — 6つの大型ミステリーを72通りの事件設定で遊ぶ試作

**開発用 / 販売HOLD**

今回、3本だった大型の伏線回収ルートを6本にしました。ランダムな文章の寄せ集めではなく、開始時に一つの大きな謎を固定し、実際に調べた記録と聞いた証言が揃ったときだけ解釈が変わるようにしています。

## 大型6ルート

1. 聞く前に書かれた答え — 誰の言葉を誰が用意したのか
2. 二つの発言のあいだ — 「止めたい」と「続ける」は矛盾するか
3. 命令のない規則 — どうして明示の命令なしでも止められなかったのか
4. 誰の言葉なら使っていいのか — 公開に対する同意はどこまであったのか
5. 異議のない記録 — 誰も反対しなかったことは賛成なのか
6. 守るために消した言葉 — 二人が守ろうとして、自分たちの発言まで伏せたのはなぜか

6つの大筋へ12組ずつの周辺設定を配分し、計72組。**72本の独立脚本ではありません**。人物・動機・小事件・環境を組み合わせる補助的な変化です。

## 試す

1. ブランチ `feature/handover-v08-six-arcs` のZIPを取得し、フォルダへ展開。
2. `index.html` をWindowsのEdgeまたはChromeで開く。
3. 第一夜と翌朝で証拠と人物を調べる。
4. 最終報告前の推理で、関連する二つの証言を照合する。
5. 結末から「別の事件を調査する」を選ぶと、異なる大筋へ移行する。

セーブは端末内のみ。JSONの読み込み・書き出しができます。旧v0.7以下の記録は旧版の物語内容を変更せず復元します。
