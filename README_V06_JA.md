# 引継ぎ室 v0.6 — 複数の伏線が一つの大きな真相へ

**現在：開発試作 / 販売HOLD**

## 今回の設計変更

以前のv0.5では、匿名の封筒を書いた人・動機・小さな事件・雰囲気を組み合わせた「72変種」が中心でした。しかし、この数では物語そのものの手応えを保証できません。

v0.6では、まず**大型の事件ルートを3本**作り、その下で人物や細かな出来事を変える設計にしました。

1. **聞く前に書かれた答え** — なぜ三人の証言の文面は同じだったのか
2. **二つの発言のあいだ** — 「止めたい」と「続ける」は矛盾するのか
3. **命令のない規則** — どうして禁止命令なしでも誰も止められなかったのか

一つの伏線だけでは結論に至らず、複数の記録と人物の証言がそろって初めて大きな回収になります。足りない場合は、未解決のまま報告できます。

**区別していること：** 大型ルートは3本、各大型ルートには小さな設定の変化が24組、合計72組。72本の独立脚本でも無限生成でもありません。

## 遊び方

このブランチをZIPで取得・展開し、`index.html` をEdgeまたはChromeで開きます。

従来の同じ画面で選択して進めます。新しいタブ・推理ツリー画面はありません。最後に「別の事件を調査する」を選ぶと、別系統の大きな真相に触れやすい順に事件が入れ替わります。

途中の記録は画面下部の「記録の管理」から書き出し・読み込みできます。旧版セーブはもとの物語を壊さないように取り込みます。

## 商用評価に向けて

- 自動テスト：`npm test`（大型ルートの成立・未回収経路・旧セーブ・既存シナリオ）。
- Windowsアプリ検証：`npm install` 後、`npm run start:desktop`。Windows実機での動作評価はまだ行っていません。
- Store向けMSIXは正式な製品登録情報・正式ロゴ・実機検証がそろうまではビルドを拒否します。
- 第三者試遊による「別のルートだと感じるか」の検証、価格・ボリューム評価が未了のため**販売HOLD**です。
