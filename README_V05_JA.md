# 引継ぎ室 v0.5 — 周回する心理ミステリー（試作）

**状態：開発中。販売HOLD。既存プロジェクトを守るため game-new の専用ブランチだけで開発しています。**

夜の工場で、事故について同じ説明を繰り返す人々。匿名の封筒には「自分で決めたと言ってください」とある。

誰が書いたのか。なぜ同じ言葉を守ろうとしたのか。誰も明確に嘘をついていなかったとしても、何が真実を語らせなかったのか。

## v0.5で新しくなったこと

- 最初に事件の真相を固定する**制約付き72パターン**（封筒の筆者4人×各人固有の動機3つ×副次事件3つ×環境描写2つ）。
- 実際に記録を調べ、封筒を確認し、必要な証人と話したときだけ**筆者に結びつく伏線が回収**されます。
- 筆者を発見しなかった周回では真相は未確認のまま。調べなかった小事件を結末で勝手に解決しません。
- 推理パートの証拠照合に、見つけた事件固有の証拠も使用できます。
- 最終報告の方針と、推理で断定したか・留保したかによって後日談の意味が変化します。
- 結末から **「別の事件を調査する」** または **「同じ事件を最初から調べ直す」** を選択可能。
- 最初の事件は端末内でランダムに決定。以後72組を一度ずつ順に巡る設計です。**72本の完全独立した物語ではありません。**
- v0.1、v0.2・v0.3、v0.4セーブの復元に対応。旧データに新しい事件の事実を後付けしません。

## 起動

1. この専用ブランチのZIPをダウンロードして展開します。
2. `index.html` をWindowsのEdgeまたはChromeで開きます。
3. 従来の3択で証拠と人物を調べ、翌朝の推理パートまで進めます。
4. 結末に進むと、同じ事件を再調査するか、別の事件を開始するか選べます。
5. 必要に応じて画面下部の「記録の管理」からJSON形式で保存・読込します。

Node.jsによる検証には `npm test` を使用。Electron起動の入口はありますが、Windows実機の操作・MSIXのインストール試験は未実施です。

## 保存の注意

- 新規周回は現在のセーブを置き換えます。残したい経路は先に記録を書き出してください。
- 無効なシード番号、未取得の証拠、整合しない推理履歴は読み込みを拒否します。
- 外部AI・ネット接続・外部アカウント・広告・ゲーム内購入フォームは使用しません。

## 商業化の保留条件

自動分岐テストが成功しても、商品として売れることは保証されません。心理の自然さ、周回の体感差、会話演出、独自の音響、Windows実機の画面確認、第三者試遊、競合調査、価格検証、Partner Center用の正式MSIXは未完了です。

**次に重要なのは、違うケースを遊んだときに本当に違う事件として感じるかを検証すること。** 共通本文が多すぎるなら、別事件の固有シーンを増やし、意味のないランダム変化は削ります。

詳細：`docs/V05_REPLAY_CASES_JA.md`
