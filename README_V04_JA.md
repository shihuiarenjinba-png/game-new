# 引継ぎ室 v0.4 — 推理パート追加 / QA版

**商用判定: HOLD。販売・公開・ストア提出はしていません。**

## 何が変わったか

これまでの心理ミステリーは主に「証人にどう質問するか」「何を報告するか」の選択でした。今回、翌朝の**最終報告直前に3段階の本格推理パート**を追加しました。

1. **疑問を選ぶ** — 書類が一致した理由 / 本人は自由に選べたか / 命令のない職場の圧力。
2. **二つの証拠を照合する** — 実際に自分で得た記録の組み合わせから選択。未発見の記録は出現しません。
3. **どこまで言えるか判断する** — 断定 / 未確認を残す / 問題を切り捨てる、のどれを報告するか決める。

選んだ証拠の関係により、「具体的な根拠あり」「部分的な裏付け」「この組み合わせからは導けない」を区別します。ただし**人物の動機を機械が確定する機能ではありません**。重要なのは、どこまで事実を根拠に書けるかをプレイヤーが考えることです。

推理の記録は最後の結末に追加反映されます。無根拠な断定、疑問の切り捨て、根拠に基づく慎重な報告は、異なる後日談を残します。**既存のエンディングの基本構造や登場人物の設定を勝手に変更していません。**

## UIの方針

- 従来と同じメイン文章 + 原則3択。新しいタブ、スコア画面、長大な設定画面は作らない。
- 証拠は既存の折りたたみ欄で読む。推理は通常の選択欄で進める。
- 推理中だけ「← 推理を一段戻す」を小さく表示し、証拠の選び直しが可能。
- 戻す操作は当該推理だけで、第一夜や翌朝の会話をリセットしない。

## セーブと互換性

- v0.4専用の保存キー、JSON書き出し形式を利用し、推理途中からの再開を可能にした。
- 旧v0.2/v0.3の記録は読み取り移行。以前の保存キーを上書きしない。
- v0.1の保存履歴についても従来の移行経路を残す。
- 旧版で物語が完了した記録は、終了済みのまま復元。推理の再実施を強制しない。
- フォーマット、歴史的選択列、推理証拠の組み合わせを検証。不正なデータを読み込まない。

## 起動と検証

ブランチ `feature/handover-v04-deduction` をZIP展開し、`index.html` をEdgeやChromeで開きます。

自動テスト: `npm test`。Windows版Electron起動は `npm install` の上 `npm run start:desktop`。ただしWindows実機GUI/MSIXのインストール実験はまだ実施していません。
