# 引継ぎ室 v0.7 — 証拠の出所と大型伏線を再監査

**開発段階 / 販売HOLD**

以前の72変種×大型3ルートの構造を保持しつつ、未調査の書類が突然現れる問題、大型の回収が自動で起きる問題、ランダム設定の偏りを修正しました。

## 変更の中心

- 大型の真相は、入口の証拠・支える証言・別の立場の証言に加え、プレイヤー自身が最後に関連する証言2つを比較したときだけ回収。
- 調べていない「署名前の記入例」などを勝手に生成しない。事実として確かめられた範囲のみ結末に書く。
- 72変種を3つの筋へ均等配分し、別の大型ルートが続けて登場する巡回順に修正。筆者4・動機3・周辺事件3・環境2は各大型ルートに含まれる。
- 事件の筆者と、その人物の心の動機を区別。証言で確かめていない動機は断定しない。
- 旧v0.6以下の記録は元の物語ルールのまま保存・再開。新規周回から新しい論理基準を使う。
- UIは既存の物語と3択・折りたたみ証拠欄を維持。新しいタブやメニューなし。

## テスト

Windows・Node.js環境で npm test。

72事件の成立経路と、52,488通りの「記録・人物の質問・翌朝の会話」の組み合わせを監査。古い分岐・セーブのテストも維持。

**注意：コードテストが合格しても、自然な物語、人間の心理、十分な遊びごたえ、Windows画面表示を保証するものではありません。**

## 大型ルートの本数

現在3本のみ。72は事件の背景変種の数で、別個の脚本72本ではありません。

有料版の企画目標として、追加の独立大型ルートを作り、ひとまず合計6本程度を検討します。ただし6本なら必ず販売できるという意味ではありません。脚本密度、プレイ時間、リプレイ時の違いを実測し、必要なら8本以上や別の品質強化策を検討します。

新規大型ルートは、証拠の出所・入手時刻、人物の知識、解釈の転換、全ランダム変種との整合性を満たすまで採用しません。
