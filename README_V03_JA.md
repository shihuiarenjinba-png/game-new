# 引継ぎ室 v0.3 — 「何が確かか」を問い直す試作

**現状:** 独立した心理ミステリー / 商品化はHOLD

## 改良内容

- プレイヤーが実際に入手した証拠だけを使い、次の場面の独白・矛盾の見え方が変わる。
- 証拠には「分かったこと」と「まだ分からないこと」を分けて記述。犯人を機械が自動判定する作品にはしない。
- 長かった証拠リストを、タイトルだけの折りたたみ式に改善。新規入手の証拠だけ最初から詳細を開く。
- 最初の選択後は冒頭の大きな説明を隠し、重要な物語部分へ焦点を移す。新しいタブや画面分割は増やさない。
- 既存の二章、分岐結果、v0.2セーブデータの形式は維持する。v0.1のセーブ移行も従来どおり。
- Windows / MSIX販売準備のビルド判定は正式製品Identity・Publisher・アセット未設定ならHOLDのまま。

## 遊び方

1. このブランチをZIPで保存し、フォルダーに展開。
2. index.html をWindowsのEdge/Chromeで開く。
3. 物語中の三つの選択肢を選び、右側・下側の「あなたが見たもの」で証拠名を選んで詳細を確認。
4. 記録は下部の「記録の管理」からJSONとして書き出し・読み込みできる。

ネットワーク・AIチャット・APIは不要。ゲーム内の購入画面もありません。プログラムの自動テストは npm test。

## 重要：まだ解決していない弱点

**今後の最優先は「選択の組み合わせの数を増やす」ことではなく、「推理の手応え」です。**

現状は丁寧な聞き取りが望ましい結果につながる傾向があり、好ましい言動を当てるゲームに見える可能性があります。次段階では、対立する複数の仮説、誰を守るかの代償、確かめた事実と錯覚の区別を、台詞と結果の違いに落とし込みます。

同時に、表示確認・クリック操作・DPI・保存継続のWindows実機QA、第三者試遊、完成プレイ時間、価格との釣り合いを検証します。実機QA未了のため販売不可。

改善の詳しい理由と次の検証項目は docs/V03_QUALITY_AUDIT_JA.md に記載しています。
