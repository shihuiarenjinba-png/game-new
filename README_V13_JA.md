# 引継ぎ室 v0.13 — 推理の途中で考えを変える心理ミステリー

**開発試作 / 商用販売HOLD**

v0.12から、6つの大型ミステリー・72種類の事件設定を維持したまま、プレイヤー自身の推理を深めました。これまでの「証拠収集→最終報告」の間に、**第一夜に立てた仮説を、翌朝の証言で再検討する**2つの判断を設けています。

## 新しい進め方

1. 第一夜：従来の資料と人物の調査（各5判断）。
2. 第一夜の終わり：**仮説を3つから1つ選びます**。まだ見ていない記録に基づく推測は候補に出しません。
3. 翌朝：従来の3つの調査を実施。最初の仮説によって人物への問いかけの描写が変化します。
4. 最終報告の直前：仮説を見直す・維持する・保留する、の3択で考えの変化を記録。
5. 最終推理：本当に入手した証拠を2つ照合し、確認できたことと推測を区別して報告。
6. 結末：選んだ仮説と実際の証拠を踏まえて振り返ります。仮説が正しいだけでは真相は開示されません。

UIは引き続き一つの物語画面、3択、折りたたみ証拠欄。オンライン接続・生成AI・広告・ゲーム内購入は不要です。

## Windowsで試す

GitHubの新しいブランチ `feature/handover-v13-hypothesis-revision` をZIPで取得・展開し、`index.html` をEdge/Chromeで開きます。

開発検査には以下が使えます。

```powershell

npm run audit:story-volume
npm run test:edge:win
npm run test:edge:accessibility:win
npm run test:edge:save:win
```
