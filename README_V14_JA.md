# 引継ぎ室 v0.14 — 考えを変えたことが報告に残る

**開発中／商品化HOLD**

v0.13で追加した「初夜の仮説→翌朝の見直し→最後の推理」を維持しつつ、**選んだ報告の方針によって、事件ごとに実際に何を書き残したかが変わる**ようにしました。正しい答えにたどり着けなかった場合にも、どの調査や照合が不足したかを説明します。

## ゲーム側の変更

- 大型6ルートそれぞれに「事実を分けて記す」「匿名で再聴取」「責任者を名指し」の結末を用意。
- 初夜の仮説3種類×翌朝の見直し3種類が、その結末の説明へ反映されます。
- 見逃した証拠を、結末で後付けの真実として示しません。本人が認めていない封筒の筆者や、未確認の雇用規則も確定させません。
- **新しいタブや画面を増やさず**、一つの物語パネル、3択、折りたたみ証拠欄を維持します。
- 仮説を見直す場面と終幕の説明を簡潔にし、重複する見出しや不要な選択肢の補足文を減らしました。
- v0.14の保存形式は独立しています。旧v0.13で仮説選択や見直しの途中だった進行も、以前の規則で再開できるようにしています。

## 取得・起動

`feature/handover-v14-consequence-simplicity` のZIPを**既存作品とは別のフォルダへ展開**し、`index.html` をMicrosoft EdgeまたはChromeで開きます。通常のプレイはオフラインで、外部AI・サーバー・広告・ゲーム内購入は不要です。

開発者向けの確認コマンド（Node.js 22以上、Edge検査はWindowsのみ）：

```powershell
npm test
npm run audit:story-volume
npm run test:edge:win
npm run test:edge:accessibility:win
npm run test:edge:save:win
```
