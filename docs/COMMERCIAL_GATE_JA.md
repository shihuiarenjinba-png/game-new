- 第一夜に続いて、翌朝の聞き取り・最終報告を描く第二章を追加。前夜の決定が続章の反応と結末に影響する。

## 有料で販売するまでの最低基準

- [ ] 第三者の試遊で基本操作が迷わず理解できる
- [ ] プレイヤーが最後に「意味のある選択をした」と感じられる
- [ ] 登場人物の発言、証拠、日時、知識状態が矛盾しない
- [ ] 単純な善悪ポイント制と感じられず、異なる選択にも合理性がある
- [ ] 独自の環境演出・音・適切なテンポを持つ（素材権利を監査）
- [ ] 競合調査、価格調査、想定プレイ時間・実プレイ時間を検証する
- [ ] Windows実機で起動、操作、保存、読込、再起動、DPI、MSIXインストール・更新・削除を確認
- [ ] 商品ページ、正式ロゴ、スクリーンショット、年齢区分、著作権・ライセンスを整備
- [ ] 正式なPartner Center登録情報とストア審査を取得

## UIの厳格なルール

1. 上部・下部ともに新しいタブは原則追加しない。
2. 主要操作をストーリーの選択肢に集約する。
3. 保存・設定・説明は一つの折りたたみ領域にまとめる。
4. 新機能が既存機能と重複したら統合・削除する。
5. モバイルとWindows双方でクリック不能、画面外ボタン、文字の重なりを必ず検査する。
6. 新機能の数より、場面の完成度と操作の単純さを優先する。

## 買い切り型の商品計画

Microsoft Storeに有料MSIXとして登録する方針。価格設定はPartner Centerで行う。アプリ内で独自の決済ページ・広告・サブスクリプション・AIチャットは作らない。

購入前の体験版公開は、完成尺と価格競争力を調査した後に判断する。現状は無料試作で、有料版や正式な製品IDは存在しない。

## MSIXを作るために必要なこと

- この新作専用の正式な IdentityName / Publisher / PublisherDisplayName
- 独自の正式なPNGロゴ4点（build/appx/ ディレクトリ）
- Windows実機と必要なSDK、Electron関連パッケージ
- 機能検証、実機UI・権利監査、Windows App Certification Kitによる検証
- パートナーセンターでの価格設定、公開設定、認証審査

現在のビルドスクリプトは STORE_IDENTITY_NAME、STORE_PUBLISHER、STORE_PUBLISHER_DISPLAY_NAME が未設定の場合に停止する。これらは本番値でのみ指定する。
