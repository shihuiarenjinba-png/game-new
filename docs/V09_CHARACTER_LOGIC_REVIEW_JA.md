## この工程で解決したこと

v0.8は6つの大型ミステリーを備えていたが、主要な二章の会話が共通していたため、事件ごとのプレイ体験に違いが出にくかった。

v0.9では新しいタブ・システム画面を加えず、既存のストーリー画面の中だけで以下を実施した。

1. **6つの固有の人物描写：** それぞれの主題に合わせ、初夜の観察・真帆への聞き取り前後・荻野との応対・佐原の連絡・最後の振り返りを別々に執筆。
2. **プレイヤーの質問の影響：** 聞き取り開始時の態度、前夜の真帆への質問、封筒を公開したか、真帆に名前を出したかで、その場の描写を変更。
3. **回収の実感：** 関連する証拠を揃え、対応する推理テーマで証言二つを照合した結末だけに、序盤の言葉・物音・不安を再解釈する短い文章を添える。
4. **調べなかった場合も物語が成立する：** 伏線を回収できない結末では、明かされなかった事柄をそのまま残す。重要な真実を回想の形で突然追加しない。
5. **小事件の偽の告白を防止：** 以前は特定の会話条件で、調べていない封筒筆者の告白まで証拠欄に現れる可能性があった。v0.9で新規周回は `case-witness` を出さず、筆者本人の確認が行われない限り筆者・動機を特定しない。
6. **保存互換性：** v0.9新規事件の識別子は `arcMode: immersive`。v0.8以下は元のモードを保護して再開でき、既存事件の設定を差し替えない。

## 人物の知識台帳（ゲーム上の入手可能時点）

| 人物 | 先に見える反応 | 質問して初めて扱える証言 | 決めつけないこと |
|---|---|---|---|
| 真帆 | 言葉を選ぶ、周囲の視線を気にする | 第一夜の具体的な停止相談、別の場所なら話せる事情、翌朝の回答 | 班長からの明示的な強制、本人の心の中、封筒の筆者 |
| 荻野 | 書類を整える、言葉を慎重に選ぶ | 原稿を整えたという説明、納期の不安、「反対はなかった」という説明 | 虚偽を指示したこと、皆を脅したこと |
| 佐原 | 仕事を続けると言ったという本人の説明 | 引用の条件、断る選択肢、署名にためらう理由 | 最初から自由な意思だったか、誰かが必ず解雇されること |
| 匿名の書き置き | 封筒の存在と短い文章 | `examine` を選んで確認した紙の具体的特徴 | 差出人の確定、筆者の本当の動機、本人の自白 |

## 大型6ルート別の書き込み

| 事件 | 演出上の中心 | 回収に必要な関連情報 |
|---|---|---|
| 聞く前に書かれた答え | 書類を揃える指先、誰の文章か分からない不気味さ | 同一文面＋荻野の説明＋真帆の返答 |
| 二つの発言のあいだ | 遅れた時計、「最後には」という言い方、発言時刻の曖昧さ | 消された相談＋真帆の発言＋佐原の選択 |
| 命令のない規則 | 掲示の端、通路への視線、言われていない命令 | 評価の掲示＋納期の説明＋真帆の雇用不安 |
| 誰の言葉なら使っていいのか | 公開範囲へのためらい、言葉の持ち主への配慮 | 同一文面＋真帆の話しづらさ＋佐原の引用条件 |
| 異議のない記録 | 空席、異論の不存在と意思の違い | 消された相談＋荻野の異論についての返答＋真帆の個別面談 |
| 守るために消した言葉 | 善意が証言の欠落を生むこと | 更新掲示＋真帆の心配＋佐原の署名へのためらい |

新しい描写は主に行動・声・ためらいなど。**証拠そのものはこれまでの選択で実際に記録されたものに限定**する。別のルートと同じ固有の事実を、説明の都合だけで流用しない。
