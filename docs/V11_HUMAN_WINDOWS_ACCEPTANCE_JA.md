**注意：** この文書の項目は、実施済みの結果ではありません。自動ブラウザ検査と人間による試遊を混同しません。

## 受入前の準備

- 対象：`game-new / feature/handover-v11-accessibility-save-qa` のZIPを別フォルダに展開。**既存の作品や旧版を上書きしない。**
- EdgeまたはChromeで `index.html` を開きます。Windowsアプリ版は必要な依存関係をインストールしたテスト環境に限って確認します。
- 次の基準を3つの異なるPC画面幅・倍率で確認します：1366px／100%、1366px／125%、1366px／150%、可能なら390px幅相当。画面サイズ・倍率を必ず記録します。
- セーブを消す前に、画面下部の「記録の管理」から既存進行をファイルへ書き出してください。ブラウザ版とアプリ版で保存領域が同一とは限りません。

## 操作・画面の受入項目

- [ ] マウスなしで Tab／Shift+Tab／Enter／Space により三択・証拠開閉・記録保存が操作できる
- [ ] 途中で画面を閉じ、同じ端末で開き直しても**同じ事件番号・選択履歴・証拠**に戻る
- [ ] JSON保存した記録を再読込した際、冒頭からの勝手なやり直しや新しい証拠の出現がない
- [ ] 日本語が途中で切れず、本文の文字サイズが読みにくくならない
- [ ] 125%／150%表示で選択肢・推理・証拠の内容が重ならない
- [ ] 長い推理から結末に進んでも、必要なボタンを探して過剰にスクロールしない
- [ ] 別事件を開始しても、前の人物の証拠が混ざらない
- [ ] セーブの書き出し／読み込みで、認証・外部ネット接続が要求されない
- [ ] PCを再起動した後も、保存した記録を復元できる

## 商用品質の停止条件（いずれかが当てはまればHOLD）

1. 証拠を読まなくても無根拠に真相を断定する、または読んだ証拠に反する真相が出る
2. 入力不能、進行停止、保存破損、同じ周回で条件が変わる
3. Windows表示倍率やキーボード操作で重大な操作障害がある
4. 複数回プレイしても実質的な違いが乏しく、購入に値する体験量を確認できない
5. 正式MSIXのIdentity・署名・インストール・アンインストール試験が未完了
6. 第三者の試遊と価格・購入意向の確認が未完了

## 自動テストと混同しないこと

- `npm test`：ランダム・証拠・推理・セーブのコード検査
- `npm run test:edge:win`：Windows Edgeヘッドレスでの6ルートのクリック完走、390px画面を含む簡易描画
- `npm run test:edge:accessibility:win`：Windows Edgeの実際のキーボード入力、途中再読み込み、100%／125%／150%表示を含む追加QA（CI環境）
- 上記3件の成功だけでは「Windows実機の人手試遊済み」でも「Microsoft Store審査可能」でもありません。

**記録時に書いてほしい情報：** OS（Windows 11のビルド）、画面解像度、表示倍率、ブラウザ名・バージョン、事件の名称、再現手順、期待した挙動、実際の挙動、発見した不自然な台詞。画像に個人情報が映っている場合は提出前に削除してください。

**保護対象：** STRATEGY MARKET全系統を含む既存の作品・リポジトリは閲覧・編集・転用しません。調査中の成果物は新規ブランチだけに追加します。
