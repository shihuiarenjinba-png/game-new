# 引継ぎ室 v0.11 — Windows Edge操作と保存再開の品質検証

**判定：自動検査PASS（GitHub-hosted Windows / Edge）／商用・実機手動試遊HOLD**

## 変更点

ゲームの操作画面・物語・ランダム分岐・セーブ形式はv0.10のまま変更しない。新規のWindows操作試験 `scripts/windows-edge-accessibility.cjs` を追加して、単純な自動クリックでは検出できなかった問題を調べる。

### 何を確認するか

- **キーボードのネイティブ入力**：Microsoft EdgeをDevTools Protocolで操作し、Tabで本編の選択肢へフォーカスし、Enterで実際に進行することを確認する。
- **途中でブラウザを本当に再読み込み**：第一夜と翌朝の途中まで進め、`Page.reload` を実行。読み込み前後の保存文字列が完全に一致し、その事件の続きを進められることを確認。
- **画面倍率・画面幅**：Edgeヘッドレスの `--window-size` だけではCSS表示領域が指定どおりにならない場合があるため、DevToolsの `Emulation.setDeviceMetricsOverride` で実際のCSS表示領域を固定。指定幅と実際の `innerWidth` が一致することまで検査する。
- **横はみ出し**：画面幅に対しHTMLの `scrollWidth` が広がりすぎないことを確認。
- **日本語本文と操作**：本文の計算済みフォントサイズが13.5pxより小さくならず、必要な証拠欄・結末後の選択肢が存在することを確認。
- **推理の継続**：再読み込み後、根拠のある大型の真相まで到達して保存履歴が同じ事件番号を指していることを確認。

## 実行方法

- Node 22以上、Windows版Microsoft EdgeがインストールされたテストPCで、
  `npm run test:edge:accessibility:win`。
- さらに既存の全ルート検査を行う場合、
  `npm run test:edge:win`。
- 物語・推理エンジンの回帰試験はOSを問わず `npm test`。

**上記は本編のローカルファイルを一時的に作成・削除する試験です。** 検証は必ず別の展開フォルダで実行し、ほかの既存作品へ適用しないでください。
