# 引継ぎ室 v0.13 — 暫定仮説と反証による見直し

**実装対象：game-new / feature/handover-v13-hypothesis-revision**
**判定：自動QA対象。Microsoft Store販売・正式MSIX・人手試遊はHOLD。**

## 今回、実際にゲームへ追加した仕組み

これまでのv0.12では、第一夜に証拠を集め、翌朝の証言を集め、終盤の3段階推理で結論を出していた。正しい証拠を選ぶ流れはあっても、**先入観を持っていたプレイヤーが新しい情報を得て考え直す経験**は乏しかった。

新規周回だけ、既存のストーリー・3択UI内で次の2つの判断を追加した。

1. **第一夜の終わり／暫定仮説：** 調べて確認できた情報から、事件固有の3つの異なる可能性を選ぶ。**見逃した重要記録に依存する仮説は表示しない**。初夜の推測は証拠としては扱わない。
2. **翌朝の終わり／仮説の見直し：** 新しく実際に聞いた証言だけを示し、「最初の見方を変える」「維持して照合する」「保留して事実だけを検証する」から選ぶ。
3. **最終報告／証拠を照合する：** 従来の独立した証拠2点の照合、対象となる問いの選択、慎重・断定・棄却の判断が引き続き必須。**暫定仮説や見直しの選択のみで大きな真相を確定することはない。**
4. **翌朝の人物反応：** 6本それぞれで、初夜に選んだ仮説に応じて、質問の仕方と登場人物の反応の描写が3通りに変化する。先入観によって会話の受け取り方が変わるが、情報を得たことにしてはいけない。
5. **最後の振り返り：** 初夜の仮説と翌朝の再検討、その後の証拠照合の違いを短く振り返る。結末の真偽や人物の行動に未確認の出来事を加えない。

### 6つの主題ごとの暫定仮説

| 大筋 | 一見するとあり得そうな説明 | 別の構造的説明 | 保留すべき未確定事項 |
| --- | --- | --- | --- |
| 聞く前に書かれた答え | 三人が同じ説明を考えた | 使う文面が先にあった | 文面を最初に用意した人物 |
| 二つの発言のあいだ | 続けるという発言が最終意思 | 停止相談が途中で消された | 発言の厳密な順序 |
| 命令のない規則 | 命令なしなら強制なし | 暗黙の規則があった | 噂と正式な規則の関係 |
| 誰の言葉なら使っていいのか | 署名は公開許可を含む | 引用には本人ごとの条件がある | 各人の同意範囲 |
| 異議のない記録 | 反対がなければ合意 | 意見を伝えにくい状況 | 発言できる機会 |
| 守るために消した言葉 | 言わないのは隠蔽のため | 誰かへの不利益を恐れた | 各人が守りたい相手 |

上記は **推測の選択肢**であり、初夜に確認していないことを発生済みの事件として扱うものではない。

## 保存と旧版の保護

- 新モードを `arcMode: deliberative`、独立した `midpoint.initial`・`midpoint.revision` として保存。JSONバックアップ形式はv13。
- 初夜を終える前には仮説を記録できない。翌朝に進む前には最初の仮説が必要。最終報告を終える前には見直しが必要。
- 途中セーブ・JSON復元・画面再読込の際、事件番号・仮説・変更した判断が一致することを確認。
- 旧v0.9以前に作った記録は旧モードのまま引き継ぎ、新しい2つの選択や新事実を後付けしない。既存リポジトリや旧ブランチを編集しない。
- 新しいタブ・常設管理パネル・課金UIは追加しない。**9つの既存調査判断に、解釈に関する2つの判断を加える**ため新規の1周は11判断＋既存の最終証拠照合（3段階）。

## 自動検査の対象

- 72設定×初夜の仮説3×翌朝の見直し3＝**648の再検討経路**について、証拠を揃えた正しい推理では大きな回収に到達できる。
- 同じ648経路で、関係の弱い証拠ペアを選べば大きな回収を得られない。
- 初夜の重要記録を見なかった72設定で、ルート固有の未来の証言や真相を表示しない。
- 6つの大型ルートで、初夜の3択が翌朝それぞれ異なる会話につながる。
- 変造セーブ（仮説未選択で朝に進む、早すぎる見直し、存在しない仮説ID等）を拒否。
- Windows Edgeで6ルートの選択操作、390px幅と画面倍率、キーボード入力、途中再読み込み、JSON書き出し／読み込みを再実行。
- 旧版のシナリオ、証拠、推理評価、保存形式の回帰テストを維持。

**重要な限界：** ここでの「独立した反応」は主に台詞・会話の進め方・後日談の分岐であり、まったく別の人物行動や別事件への大規模な分岐ではない。プレイ時間、驚き、心理描写の人間らしさ、6周遊んでも飽きないかは第三者試遊で判断する。
