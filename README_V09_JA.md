# 引継ぎ室 v0.9 — 6つの事件で人物の反応が変わる心理ミステリー

**開発試作／有料販売HOLD**

6つの大型ルートはそのままに、同僚・班長・負傷した本人の言葉や仕草をルートごとに執筆し直しました。第一夜にどの書類を確認し、誰にどう聞いたかによって、翌朝の場面や最後の回収の意味が変わります。

## 今回の改善

- 6種類の大型ルートに固有の人物の言葉と情景を用意。
- 質問の態度、封筒を公開したか、真帆への質問のしかたに応じた反応。
- 伏線を正しい証拠で回収したときだけ、最初の台詞の意味を読み替える短い終幕を表示。
- 聞き取らなかった手紙の筆者の「本人が認めた」という記録や、裏付けのない心の動機を新しい周回では表示しない。
- 新しいタブやステータス画面は作らず、従来の物語・3択・折りたたみ証拠欄だけを使う。
- v0.9のセーブを独立し、旧v0.8以下を過去の事件内容のまま復元。
- 72種のケース設定×729通りの調査選択＝**52,488通り**の交差テストで新しい心理描写と証拠出現の不整合を監査。

## 遊び方

1. このブランチ `feature/handover-v09-character-reactions` をZIPで取得。
2. すべて展開し、`index.html` をEdgeまたはChromeで開く。
3. 第一夜と翌朝の情報を集め、最終報告直前の推理で根拠となる証言を比較する。
4. 結末で「別の事件を調査する」を選ぶと、異なる大型ルートに移り、同じ人物が別の文脈で違って見える。

すべてオフライン。ゲーム内の独自課金・広告・アカウント・外部AIはありません。Node.jsを導入済みの環境では `npm test` で自動テストを実行できます。
